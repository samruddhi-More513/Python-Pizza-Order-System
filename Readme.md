# 🍕 Pizza Order System (Python)

A simple Python project that simulates a pizza ordering system using basic programming concepts.

## 🚀 Features
- Select pizza size (Small, Medium, Large)
- Add extra toppings (pepperoni, cheese)
- Automatic bill calculation

## 🧠 Concepts Used
- Conditional statements (if-else)
- User input handling
- Basic logic building

## 💡 What I Learned
- Writing clean conditional logic
- Handling user inputs effectively
- Structuring a Python program

## ▶️ How to Run
1. Make sure Python is installed on your system
2. Download or clone this repository
3. Open terminal in the project folder
4. Run the file:
   python main.py

## 🔧 Future Improvements
- Add GUI using Tkinter
- Store order history
- Improve user experience
